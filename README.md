# رویداد ملی خلاقیت و نوآوری آینه

نسخه یکپارچه صفحه اصلی رویداد آینه، ساخته‌شده از خروجی‌های جداگانه Codia و فوتر یکپارچه پروژه.

## ساختار صفحه اصلی

1. هدر + هیرو + شاخص‌های ساختاری رویداد
2. معرفی آینه
3. محورها و نظام مسائل
4. دو مسیر ورود
5. مسیر ۹ مرحله‌ای رویداد
6. حمایت‌ها و فرصت‌ها
7. ثبت‌نام
8. پرسش‌های متداول
9. فوتر

## اجرا

```bash
npm install
npm run dev
```

برای بررسی نسخه production:

```bash
npm run build
npm run preview
```

## نکات یکپارچه‌سازی

- پروژه React 18 + TypeScript + Vite + Tailwind است.
- صفحه به‌صورت RTL و با فونت‌های Vazirmatn و Estedad پیاده‌سازی شده است.
- عناوین ۱۵ مسئله در بخش محورها با عناوین نهایی پروژه هماهنگ شده‌اند.
- در FAQ شماره آیتم باز نارنجی و آیتم‌های بسته خاکستری هستند؛ فقط پاسخ موجود در خروجی Codia در این مرحله نمایش داده می‌شود.
- لوگوهای فوتر در bundle پروژه قرار گرفته‌اند.
- تصاویر تولیدشده توسط Codia فعلاً از CDN همان خروجی‌ها خوانده می‌شوند و در مرحله بعد می‌توان آن‌ها را local کرد.
