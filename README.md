# Ayene Event

Frontend for «رویداد ملی آینه».

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- TanStack Query

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Planned routes

- `/` Landing
- `/register` Registration flow
- `/tracking` User tracking
- `/contact` Contact request
- `/admin` CMS / Admin
