# ساختار کامل و خالی دیتابیس آینه

این ۱۶ فایل از تاریخچهٔ **واقعی** migration پروژه managed Supabase استخراج شده‌اند. هفت فایل قبلی مخزن به‌تنهایی کافی نبودند.
هیچ ثبت‌نام، پیام، session یا فایل کاربران منتقل نشده است. **hash رمز مدیر قبلی** عمداً از migration حذف شده و مدیر جدید باید با رمز جدید ساخته شود.
قبل از اجرا سرویس‌های Auth و Storage خود Supabase را راه‌اندازی کنید تا جداول داخلی `auth.users` و `storage.objects` موجود باشند؛ صرفاً راه‌اندازی `db` کافی نیست.
اسکریپت `bash deploy/install-schema.sh` شرط خالی‌بودن schema `public` را چک می‌کند و فایل‌ها را به‌ترتیب اجرا می‌کند.
در صورت خطای migration، دوباره روی دیتابیس نیمه‌ساخته اجرا نکنید؛ نیازمند بررسی است. این فایل‌ها هنوز end-to-end روی سرور ایران تست نشده‌اند.
